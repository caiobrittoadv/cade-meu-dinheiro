# Contributing

Obrigado por contribuir com o Cadê Meu Dinheiro?

Antes de contribuir, leia `README.md`, `CLAUDE.md` e a documentação em `docs/`.

Contribuições devem preservar:

- integridade financeira;
- segurança;
- privacidade;
- simplicidade;
- testabilidade.

Uma Pull Request deve explicar o problema, a solução, os módulos afetados, os testes e qualquer impacto no modelo de dados ou nas regras financeiras.

Alterações no Motor Financeiro exigem testes cobrindo os invariantes afetados.

Use apenas dados sintéticos em testes e fixtures públicos.
