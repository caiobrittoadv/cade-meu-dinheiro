# Security Policy

O Cadê Meu Dinheiro? trabalha com informações financeiras potencialmente sensíveis.

Nunca publique em issues ou PRs:

- credenciais;
- API keys;
- tokens;
- dados bancários;
- documentos financeiros reais;
- informações pessoais identificáveis;
- faturas ou extratos reais.

Para vulnerabilidades de segurança, não publique detalhes exploráveis em uma issue pública. Entre em contato diretamente com os mantenedores por canal privado.

Princípios:

- menor privilégio;
- isolamento por Financial Space;
- storage privado;
- secrets fora do código;
- criptografia;
- auditoria;
- validação de uploads;
- rate limiting;
- autorização no backend.
